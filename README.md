Here are defenitions of uni disciplines:
  1. ПЗМС -- Прикладные задачи математической статистики. This subject is devoted to the study of analysis methods and the application of acquired skills on real datasets.
  Within the framework of this discipline, a course work was carried out on the topic of analyzing gold prices in order to identify a protective asset.
  2. РБД -- Разработка баз данных. in this discipline, there was a detailed introduction to postgresql, its features, for example, triggers, transactions, etc.
  3. ТИМО -- Технологии и инструментарий машинного обучения. Within the framework of this subject, a basic machine learning course was completed, for example:
    - logistic regression
    - ensemble methods
     - classification
     - clustering
     - EDA
